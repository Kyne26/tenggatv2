# Tenggat

1. Pastikan Node.js terpasang.
2. `npm install` lalu `npm run build` (membuat `assets/css/output.css`).
3. Tes lokal: `python -m http.server 8000`, buka `localhost:8000`.
4. Upload folder ke Netlify Drop / GitHub Pages (wajib HTTPS agar PWA aktif).
5. HP Android Chrome: menu ⋮ → Instal aplikasi. iPhone Safari: Bagikan → Tambah ke Layar Utama.
6. Setiap mengubah file, naikkan `V` di `sw.js` (mis. `tenggat-v2`) agar cache diperbarui.
